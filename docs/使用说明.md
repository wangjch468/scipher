# 使用说明

## 启动

- **Python 版**：双击 `src/密码工具.py`，或 `python src/密码工具.py`
- **bat 版**：双击 `src/密码工具.bat`

两版菜单与密文完全互通，任选其一。

## 主菜单

```
1) 混合加密(#)
2) 混合解密(#)
v) 切换版本
c) 命令式CLI
q) 退出
```

只保留混合入口，不再提供单独的文件加密菜单——文本与文件都可在一个流程里处理。

## 混合加密（菜单 1）

回车进入内嵌文本编辑器：

| 操作 | 按键 |
|---|---|
| 输入文字 | 直接打字（支持中文 / 粘贴） |
| 移动光标 | 方向键 |
| 换行 | 回车 |
| 删除 | 退格 / Delete（文件块整块删除，不会删坏） |
| 插入文件 | `F8`（自动识别为文件块，显示完整路径） |
| 完成 | `F5` |
| 取消 | `Esc` |

编辑器里有可见光标（反色块高亮当前字符），文件作为不可拆的整块保护。手打的 `⟦文件:路径⟧` 一律当普通文字，不会被误识别成文件——只有 `F8` 插入的才算文件。

完成后输入输出文件路径，加密过程显示进度条与 ETA：

```
加密中...  45%[########--------]  ETA 00:03
```

计算先写 `jm.tmp`，完成后转存到输出文件并删除缓存。

## 混合解密（菜单 2）

输入密文或密文文件路径，解密完成后统一输出汇总：

- 内容按**原始顺序单行内联**展示，文件显示为 `[文件：名（字节数）]`
- 列出文件清单
- 解密出的文件**自动落盘**到当前目录
- 输入清单里的编号可**再次下载**一份真实新文件（带 `_下载N` 后缀，打印完整绝对路径）
- 按 `q` 退出

## 版本切换（菜单 v）

在 v2.2 / v2.3 / v2.4 之间切换。默认 v2.4。

## 命令式 CLI（菜单 c）

无需交互菜单，直接传参：

```
enc <文本>              加密文本
dec <密文>              解密文本
file-enc <文件> <输出>  加密文件
file-dec <密文> <输出>  解密文件
mix-enc <内容> <输出>   混合加密（# 分隔文本与文件）
mix-dec <密文文件>      混合解密
```

bat 版也可通过环境变量 `SCIPHER_ARGS` 传参，例如：

```
set SCIPHER_ARGS=enc ABC123
密码工具.bat
```

## 错误处理

所有解码失败只显示一行 **`解码失败`**，不抛堆栈、不暴露内部细节。

## 常见问题

**Q：双击后报 `[Errno 13] Permission denied: 'jm.tmp'`？**
旧版 bug，缓存用相对路径导致。当前版本已修复——缓存锚定脚本所在目录，双击时从 System32 启动也能正常写。若仍遇到，请确认运行的是 `src/` 里的最终版。

**Q：bat 版输入不回显 / 卡住？**
已修复。非编辑器输入统一用 `ReadKey($false)` 逐键读取并主动回显，支持中文、空格、反斜杠、粘贴、退格。

**Q：加密大文件很慢？**
bat 版已优化：热点路径（v1 编解码、压缩/展开、倒置）改用 .NET 原生循环 + 查表，200KB 文件从约 46 秒降到约 4 秒。更大的文件建议用 Python 版。
