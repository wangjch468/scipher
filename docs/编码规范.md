# 编码规范

scipher 是一套自定义字符串 / 文件编码规范，历经 v1.0 → v2.4 迭代。本文是速览，完整逐轮纠正记录见 `old/对话记录.md`（约 3800 行、89 条用户消息）。

## 基础字符表（shortlex 表）

| 类别 | 位数 |
|---|---|
| A-Z | 26 |
| 0-9 | 10 |
| 拼音四声 | 4 |
| 半角标点 | — |
| 全角标点 | — |
| 声调符号 | — |

字符编码为 `axn` 形式，其中 `k = 2^a - 2 + n`。

**关键约定**：四声只占 4 位；轻声不标调。

## 版本演进

### v1.0 — 中英分块
- 中文块 `P[...]`、英文块 `[...]`，块间用 `·` 连接。

### v2.0 — 同码长压缩
- 同位数压缩为 `axb/c` 形式。**压缩不带括号**。

### v2.1 — 原子倒置
- 块内原子反序，数字作为整体处理。自反操作（`invert`）。

### v2.2 — 固定 2 栏栅栏
- 栅栏置换：`123456 → 135246`。
- **栏数固定为 2**，不做成可配参数。

### v2.3 — Base64 前置
- 明文先 Base64，再走 v2.2。
- 顺序固定：Base64 在 v2.2 **之前**。
- 效果：输出还原为原始汉字（不再带 P 块标记）。

### v2.4 — 文件格式
- 文件格式：`加密文件名@加密内容Base64`。
- 解密时支持自动还原文件名与内容。

## 设计约定（最终定稿）

- **错误只显示 `解码失败`**，不输出堆栈或内部细节。
- **菜单只保留混合入口**，不做单独文件入口。
- **汇总按原始顺序单行内联**，文件显示为 `[文件：名（字节数）]`。
- **编号下载是真实写文件**，带 `_下载N` 后缀，打印完整绝对路径。
- **编辑器**：文件标记 `⟦文件:路径⟧` 仅由 `F8` 插入；手打同名文本一律当普通文字，避免误识别。
- **Windows 适配**：不导入 `termios`，`msvcrt` 走独立分支。

## 大文件处理

- 64K Base64 分块 + 流式 emit，避免双重 Base64 + axn 展开导致的 MemoryError。
- 逐块解密逐块刷新进度条，解决"卡 0%"。
- 进度条：动态宽度 + ETA（`mm:ss`），逐块刷新。

## 互通性

- Python 版为真相源，bat 版与其密文双向一致。
- 7 组黄金向量密文两版一致，作为回归基准。
- bat 版移植时踩过三个坑（均已修复）：PowerShell 智能引号当分隔符、`@{}` 哈希表大小写不敏感覆盖大写字母、v2.2 压缩漏按 `+` 分段。
