# scipher 密码工具

一套自定义字符串 / 文件编码规范（v1.0 → v2.4）及离线工具链。纯本地运行，不联网。

## 项目结构

```
密码工具/
├── src/
│   ├── 密码工具.py      # Python 核心（CLI + 内嵌编辑器）
│   └── 密码工具.bat     # bat 自包含版（内嵌 PowerShell 引擎）
├── docs/
│   ├── 使用说明.md
│   └── 编码规范.md
└── README.md
```

## 两个版本

| 版本 | 文件 | 说明 |
|---|---|---|
| Python | `src/密码工具.py` | 核心实现，约 112KB。双击或 `python 密码工具.py` 运行 |
| bat | `src/密码工具.bat` | batch 引导 + 内嵌 PowerShell 引擎，自包含。双击运行 |

**两版密文双向互通**：同一明文在两版加密结果一致，任意版本加密的密文另一版本都能解。

## 快速开始

双击 `src/密码工具.py`（或命令行 `python src/密码工具.py`），也可双击 `src/密码工具.bat`。两者都进入同一套菜单：

```
1) 混合加密(#)
2) 混合解密(#)
v) 切换版本
c) 命令式CLI
q) 退出
```

- **混合加密**：回车进入内嵌文本编辑器，直接打字；`F8` 插入文件、`F5` 完成、`Esc` 取消。
- **混合解密**：输入密文，文件自动落盘；解密完成后按编号可再次下载一份真实文件（带 `_下载N` 后缀）。
- **命令式 CLI**：支持 `enc` / `dec` / `file-enc` / `file-dec` / `mix-enc` / `mix-dec`，便于脚本调用。

## 编码规则速览

- **v2.2**：固定 2 栏栅栏（`123456 → 135246`）
- **v2.3**：明文先 Base64，再走 v2.2
- **v2.4**：文件格式 `加密文件名@加密内容Base64`，支持还原

详见 [docs/编码规范.md](docs/编码规范.md)。

## 缓存

计算过程写 `jm.tmp`，已完成即转存到输出文件并删除。缓存路径锚定脚本所在目录，双击（cwd 为 System32）也不会报权限错。

## 备注

- 两版工具**必须放在同一目录**（bat 引导层按相对路径定位自身引擎）——当前都在 `src/`。
- 中文环境变量：程序内部已 `chcp 65001`，无需手动设置。
